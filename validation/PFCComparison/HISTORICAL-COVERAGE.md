# PFC official verification coverage

> Historical diagnostic/coverage evidence from the 28–29 October 2026 campaign. Capability statements concern that configured source snapshot and application path, not an exhaustive current-core feature list. Migration changes links and artifact labels, not the recorded outcome.

Date: 29 October 2026. PFC is proprietary Itasca software; the reference examples and documentation are public. This inventory covers all fifteen PFC 7.0 verification-index entries, cross-checked against the PFC 9.0 index. It does not claim all Itasca tutorials or applications.

The two existing Md0 beta=0.2 and beta=0.6 subcases retain their original reports and records. The complete sixteen-value Md0 sweep is verified as a new independent case: four runs, 64 ball/run checks and 4,004 retained native frames. [English report](cases/pfc-linear-restitution-md0-sweep/REPORT.md) and independent physics audit (retained locally; not included) retain the evidence. The Md1 row requires no-tension dashpot behavior and remains separate.

The common-floor material mapping is algebraic: harmonic(e_ball,1)=2 e_ball/(e_ball+1); choose e_ball=e_contact/(2-e_contact). At e_contact=0 the implemented zero branch gives critical damping. All source values, original positions and the normal contact law are preserved. This is not an empirical calibration.

The disk rotation issue is active: PFC2D uses I=mR^2/2, while the configurable FunDEM sphere uses I=2mR^2/5 and has no independent mass/inertia override. Changing density or using an LS thin disk does not preserve the official contact family and equations.

PFC local damping is proportional to force magnitude with a velocity-sign rule; FunDEM viscous particle damping is proportional to velocity. Equal numeric coefficients would not make these methods equivalent.
